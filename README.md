# Deep Learning Notebooks

A hands-on collection of notebooks for learning optimization and neural networks from first principles. The repository moves from linear-model optimization and perceptrons to multilayer neural networks, backpropagation, and small applied projects.

## What You Will Learn

- Batch, stochastic, and mini-batch gradient descent
- The perceptron trick and hinge-loss classification
- Neural-network gradient descent, feature scaling, and early stopping
- Backpropagation for classification and regression
- Practical experiments with image, customer, social-network, and admission data

## Installation

The root requirements file provides the broad environment used across the repository.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m pip install jupyter
```

Alternatively, install Jupyter through your preferred distribution, such as Anaconda or Miniconda. Focused dependency lists are also available in [Gradient_Descent_from_Scratch/requirements.txt](Gradient_Descent_from_Scratch/requirements.txt) and [Perceptron-Demo/requirements.txt](Perceptron-Demo/requirements.txt).

## Running the Notebooks

From the repository root, start Jupyter with:

```powershell
jupyter notebook
```

Open a notebook from the guide above and run its cells in order. Some notebooks expect to be run from their own project directory. When a relative file path fails, change into the directory containing that notebook before starting Jupyter, or update the path for your local working directory.

For example:

```powershell
Set-Location ".\Perceptron-Demo"
jupyter notebook
```

The directory names contain spaces and parentheses, so quote paths when using them in a shell command.

## Troubleshooting

- Paths beginning with `/content/` are Google Colab paths. Replace them with a local path, or place the data in the expected local directory.
- Paths beginning with `/kaggle/input/` are Kaggle paths. Download the referenced dataset and update the path when running locally.
- `perceptron_training.ipynb` contains an older absolute Windows path. Update it to the location of this checkout before running that notebook.
- TensorFlow may run on CPU on native Windows. GPU execution can require a separately supported setup such as WSL2.
- The graduate-admission notebook relies on data that is not bundled in this repository.
- Existing filenames and folders use mixed naming conventions, including `chrun` in the customer-churn notebook. Links in this README preserve those names as they exist on disk.

## Generated Files and Contributions

Notebook checkpoints, Python cache directories, VS Code settings, and the local `.deepLearning` environment are ignored by Git. Keep generated outputs and machine-specific files out of commits unless they are intentionally part of an example.

When adding a notebook, keep its data paths documented, make the execution order clear, and add it to the relevant section of this README. Changes should preserve the repository's educational, notebook-first focus.
